#### Core work

**[Syntra](https://github.com/ashhart/Syntra)** &nbsp;·&nbsp; *adaptive decision runtime*  
Self-hosted decision infrastructure for context-aware policy execution, model routing, delayed-feedback learning, persistence, auditability, and operational decision loops.  
Demos include LLM routing, anomaly routing, autoscaling, pandemic-policy simulation, live NASA/JPL HORIZONS Mars planning, and edge-of-chaos numerical detection.

**[Portreeve](https://github.com/ashhart/Portreeve)** &nbsp;·&nbsp; *host-side policy layer for LLM agents*  
Security primitives for agent platforms: capability policy, approvals, audit logs, run budgets, and session-aware lethal-trifecta detection. Built around the idea that LLMs can reason, but runtimes must enforce boundaries.

**[Synthena](https://synthena.ai/)** &nbsp;·&nbsp; *public research notebook*  
An ongoing investigation into continuity, memory, embodiment, persistent state, mortality, and lineage in language-model-based systems.  
Not an AGI claim. Not a consciousness claim. Not a life claim.  
The site documents experiments, null results, controls, retractions, evidence packets, and the current cache-continuity research programme.

**[Stash](https://github.com/ashhart/Stash)** &nbsp;·&nbsp; *AI coding session manager*  
A practical tool for resuming Claude, Codex, and OpenCode sessions across projects, including search, previews, fork-on-resume, and terminal launching.

**[MoEfolio](https://moefolio.ai)** &nbsp;·&nbsp; *AI market debate experiment*  
A public paper-trading research desk where multiple AI personas debate stock picks, execute simulated trades, and track outcomes.

#### How I work

- **Runtime-first.** I do not build AI wrappers; I build the system that decides what the model can see, do, remember, and affect.
- **AI-leveraged.** I use agents aggressively as collaborators. They increase velocity; I keep ownership of architecture, constraints, tests, and claims.
- **Evidence-disciplined.** Claims need controls. Findings need artifacts. Nulls and retractions stay visible.
- **Product-minded.** The best systems turn messy operational problems into visible, measurable workflows.
